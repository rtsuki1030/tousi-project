# 投資シミュレーター

自分専用の投資ポートフォリオ・シミュレーター。実際の価格データを使い、AIが自動で銘柄を発掘・売買します。

## 公開URL

https://rtsuki1030.github.io/tousi-project/

## 主な機能

- 株式・暗号資産の売買記録、資産推移・配分のグラフ表示
- 米国株（Twelve Data）・暗号資産（CoinGecko）の実価格自動取得（日本株は無料APIがないため手動入力）
- AI運用タブ：保有銘柄とウォッチリストの実価格をもとに、移動平均のモメンタムで自動売買
- 自動探索：AIが暗号資産の時価総額上位・主要株式プールから新しい投資先候補を自分で見つけて入れ替え

## データについて

データはブラウザのlocalStorageにのみ保存されます（サーバーには送信されません）。端末やブラウザを変えると引き継がれないため、設定タブの「データをエクスポート」で定期的にバックアップしてください。

## APIキーの設定

「設定」タブで [Twelve Data](https://twelvedata.com/pricing) の無料APIキーを登録すると、米国株などの実価格取得・AI自動売買が有効になります。
